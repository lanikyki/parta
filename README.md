# Парта — онлайн-класс для репетиторов

Сервис для репетиторов: видеоурок, общая доска, переписка с учениками и ИИ-помощник. Подходит для любого предмета и возраста — от школьной математики до английского для взрослых. Всё работает прямо в браузере — ученику ничего не нужно устанавливать.

## Что умеет

**Главная страница** — рассказ о сервисе: возможности, для кого, как начать, предметы, вопросы и ответы, кнопка «Начать бесплатно» и форма «Остались вопросы?».

**Регистрация и вход** — по почте и паролю. При регистрации на почту приходит 6-значный код подтверждения. Забытый пароль можно сменить по коду из письма («Забыли пароль?» на странице входа).

**Кабинеты**
- Репетитор: создаёт уроки по любому предмету (сразу или по расписанию), копирует ссылку для ученика, приглашает учеников ссылкой-приглашением, переписывается с ними, подбирает задачи с помощью ИИ, видит конспекты прошедших уроков.
- Ученик: входит в урок по ссылке или коду, переписывается с репетитором, может написать в поддержку, видит конспекты своих уроков.
- Администратор (почты из `ADMIN_EMAILS`): админка `/admin` — обращения с сайта, сообщения в поддержку, пользователи и журнал событий.

**Сообщения** (`/messages`, ссылка в шапке со счётчиком непрочитанных)
- Переписка репетитора и ученика между уроками: ссылки кликабельные, видно «Прочитано», на телефоне — как в мессенджере.
- Ученик попадает в список репетитора сам: когда заходит на его урок со своим аккаунтом или регистрируется по ссылке-приглашению. Ссылка-приглашение — в кабинете репетитора (карточка «Мои ученики») и в «Сообщениях».
- Репетитор может вставить в сообщение ссылку на урок одной кнопкой.
- «Написать в поддержку» — вопрос администраторам; они отвечают там же, в «Сообщениях».
- Если получателя нет на сайте, ему придёт письмо о новом сообщении (когда настроена почта, см. «Почта»).

**Комната урока**
- Видео и звук до 20 участников, показ экрана, индикатор «кто говорит».
- Доска: ручка, маркер, текстовыделитель, ластик, линии, стрелки, фигуры, текст с формулами, формулы LaTeX, графики функций, картинки, PDF-презентации (каждая страница — отдельный лист), лазерная указка, листы с клеткой/линейкой/точками, отмена и повтор, масштаб.
- Режимы репетитора: «Все за мной» (ученики видят тот же лист) и «Только я рисую».
- Чат с формулами (`$x^2$`), история сохраняется.
- «Итоги урока»: ИИ собирает конспект и домашнее задание по доске и чату, конспект появляется в кабинетах.
- Работает на телефоне, планшете и компьютере. Доска и чат сохраняются, даже если обновить страницу.
- Можно войти и без камеры или микрофона (или если их заняла другая программа, например Zoom): урок откроется, а сайт подскажет, что случилось.

**ИИ-помощник** — объясняет темы по шагам, как репетитор: сначала подсказка, потом решение. Учитывает предмет и уровень ученика (класс, студент или взрослый). Два режима: «Быстро» (короткие подсказки за несколько секунд) и «Подробно» (умная модель, отвечает дольше).

## Запуск на своём компьютере

Понадобится [Node.js](https://nodejs.org) версии 22 или новее — на сайте нажмите кнопку «LTS» и установите как обычную программу.

### Самый простой способ

**Windows:** распакуйте архив (правой кнопкой → «Извлечь всё») и дважды щёлкните файл `start-windows.bat`.

- Если Windows спросит, точно ли запускать файл, нажмите «Запустить» (или «Подробнее» → «Выполнить в любом случае»).
- Если брандмауэр спросит про доступ к сети — нажмите «Разрешить доступ».

**macOS и Linux:** откройте терминал в папке проекта и выполните `npm run dev:all`. На macOS сначала установите видеосервер: `brew install livekit`.

Скрипт сам установит библиотеки, создаст файл настроек `.env.local`, скачает и запустит видеосервер, запустит сайт, откроет http://localhost:3000 и проверит, что всё работает. Первый запуск занимает несколько минут, следующие — секунды. Пока работаете с сайтом, не закрывайте чёрное окно. Чтобы остановить — закройте его или нажмите `Ctrl+C`.

Как посмотреть урок с двух сторон: зарегистрируйтесь как репетитор, создайте урок и откройте ссылку на урок в окне инкогнито (в Chrome и Edge — `Ctrl+Shift+N`). Это будет ученик. Когда браузер спросит про камеру и микрофон, нажмите «Разрешить».

Код подтверждения при регистрации на своём компьютере письмом не нужен: пока почта не настроена, он показывается прямо на странице (и пишется в чёрном окне).

Камера и микрофон работают только на этом компьютере (по адресу localhost) или на сайте с https. Сам сайт можно открыть с телефона или другого компьютера в той же Wi‑Fi-сети — по адресу из строки `Network: http://192.168…:3000` в чёрном окне: войти, переписываться и рисовать на доске получится, но камеру и микрофон браузер на таком адресе не включит (в урок можно зайти и без них). Чтобы показать сайт другу, есть раздел «Показать сайт другу», а для занятий с настоящими учениками сайт нужно выложить в интернет.

### Файл настроек `.env.local`

Все настройки — в файле `.env.local` в папке проекта. Он появляется после первого запуска. Открыть: правой кнопкой → «Открыть с помощью» → «Блокнот». После изменений сохраните файл, закройте чёрное окно и снова запустите `start-windows.bat` (или `npm run dev:all`) — скрипт проверит новые настройки и напишет, если что-то не так. Отдельно проверку можно запустить командой `npm run check`.

### ИИ-помощник

Подходит любой сервис с OpenAI-совместимым API: DeepSeek, Qwen, OpenRouter или сервис-посредник, который выдал ключ вида `sk-...`.

1. Впишите в `.env.local` адрес API и ключ. Оба есть на сайте, где вы получили ключ; адрес обычно заканчивается на `/v1`.

```bash
AI_BASE_URL=https://адрес-сервиса/v1
AI_API_KEY=sk-ваш-ключ
```

   Если сервис выдал строку подключения целиком (`{"_type":"newapi_channel_conn","key":"sk-…","url":"https://…"}`), можно вставить её в `AI_API_KEY` как есть, а `AI_BASE_URL` оставить пустым.
2. Перезапустите `start-windows.bat`. Скрипт проверит ключ, сам допишет `/v1` к адресу, если его не хватает, выберет модели и впишет их в `AI_MODEL_SMART` (умная — конспекты и подробные объяснения) и `AI_MODEL_FAST` (быстрая — подсказки). Если всё в порядке, в окне появятся строки `[OK] ИИ: … отвечает`.

Если что-то не так, проверка напишет, что исправить, а сайт покажет причину прямо в сообщении «ИИ не ответил: …». Модели можно поменять вручную: список доступных проверка тоже показывает.

**Скорость ответа.**
- В режиме «Быстро» модель отвечает сразу, без долгих «размышлений»: первые слова — обычно через 2–5 секунд.
- В режиме «Подробно» и при подборе задач и итогах урока умная модель может думать 20–60 секунд. На экране в это время идёт счётчик «Думаю… N с».
- Если основная модель долго молчит, сайт параллельно спрашивает вторую и показывает ответ той, что успела первой. Если модель выдаёт ошибки, сайт на 15 минут переключается на другую.
- Если ответа так и нет, появится причина и кнопка «Повторить».

Сервисы-посредники иногда сами отвечают медленно или с ошибками. Если это повторяется постоянно, попробуйте другую модель или другой сервис.

### Запуск вручную

Если не хотите пользоваться скриптом:

1. Откройте терминал в папке проекта. Windows: откройте папку `parta` в Проводнике, в адресной строке сверху напишите `cmd` и нажмите Enter. macOS: откройте «Терминал», напишите `cd `, перетащите папку в окно и нажмите Enter.
2. Установите библиотеки (один раз) и создайте файл настроек: `npm install`, затем `copy .env.example .env.local` (Windows) или `cp .env.example .env.local` (macOS, Linux).
3. Запустите видеосервер LiveKit в отдельном окне терминала ([страница загрузки](https://github.com/livekit/livekit/releases)):
   - Windows: скачайте архив `livekit_..._windows_amd64.zip`, распакуйте, откройте папку в `cmd` и выполните `livekit-server.exe --dev`;
   - macOS: `brew install livekit`, затем `livekit-server --dev`;
   - Linux: `curl -sSL https://get.livekit.io | bash`, затем `livekit-server --dev`.

   Ключи в `.env.example` уже подходят для этого режима.
4. Запустите сайт командой `npm run dev` и откройте http://localhost:3000. Остановить — `Ctrl+C`.

После изменения `.env.local` перезапустите `npm run dev`. Если видеосервер не запущен, на экране входа в урок появится кнопка «Открыть доску и чат без видео».

## Почта: коды и уведомления

При регистрации и смене пароля сайт отправляет на почту 6-значный код, а ещё письма о новых сообщениях. Пока почта не настроена, письма не уходят: код пишется в чёрном окне (строка «Код для …»), а при запуске на своём компьютере — ещё и на странице. Для настоящих учеников почту нужно настроить. Подойдёт обычный бесплатный ящик — лучше завести отдельный для сайта, например `parta.online@yandex.ru`.

Нужен не обычный пароль от почты, а **пароль приложения** — отдельный пароль, который почта выдаёт программам:

- **Яндекс:** откройте [id.yandex.ru](https://id.yandex.ru) → «Безопасность» → «Пароли приложений» → «Почта», придумайте название (например, «Парта») и скопируйте пароль. Ещё в Яндекс Почте откройте шестерёнку → «Все настройки» → «Почтовые программы» и включите «С сервера imap.yandex.ru по протоколу IMAP» и «Пароли приложений и OAuth-токены» — без этого Яндекс не пустит сайт.
- **Mail.ru:** настройки аккаунта → «Безопасность» → «Пароли для внешних приложений» → «Добавить».
- **Gmail:** сначала включите двухэтапную аутентификацию (myaccount.google.com → «Безопасность»), затем откройте [myaccount.google.com/apppasswords](https://myaccount.google.com/apppasswords), придумайте название и скопируйте пароль из 16 букв.

Впишите почту и пароль приложения в `.env.local`:

```bash
SMTP_USER=parta.online@yandex.ru
SMTP_PASS=пароль-приложения
```

Адрес почтового сервера для Яндекса, Mail.ru, Gmail и Rambler подставится сам. Для другой почты (например, на своём домене) впишите ещё `SMTP_HOST` — его пишут в справке почты. Если почта требует порт 587, добавьте `SMTP_PORT=587`. Имя отправителя меняется в `MAIL_FROM` (по умолчанию «Парта»). Пишите туда только имя или ровно тот же адрес, что в `SMTP_USER`: письма от чужого адреса почта не отправит.

Перезапустите сайт. Если всё верно, при запуске появится строка `[OK] Почта: вход в smtp.yandex.ru выполнен`. Если нет — проверка напишет причину (чаще всего вписан обычный пароль вместо пароля приложения).

**Если письмо не ушло.** Когда порт 465 не отвечает, сайт сам пробует порт 587. Если не получилось и так, регистрация не обрывается: на странице будет «Письмо пока не отправилось», а код запишется в чёрном окне (строка «Код для …») — его можно продиктовать, а через минуту нажать «Отправить код ещё раз». Причина «нет связи с почтовым сервером» чаще всего в VPN или антивирусе: они закрывают почтовые порты. Выключите VPN (или добавьте программу в исключения) и проверьте ещё раз.

**Проверка.** Войдите как администратор → «Админка» → блок «Что подключено» → «Отправить тестовое письмо себе». Письмо придёт на почту вашего аккаунта; если его нет — загляните в «Спам», а если отправить не удалось, на экране будет причина.

**Письма о сообщениях.** Если получатель не заходил на сайт больше 3 минут, о первом непрочитанном сообщении ему сразу уходит письмо со ссылкой на переписку — не чаще раза в полчаса на одну переписку. Сообщения в поддержку приходят письмом администраторам из `ADMIN_EMAILS`. Ссылки в письмах ведут на домен из `DOMAIN` (если задан) или на адрес, по которому открыт сайт.

**Когда писем станет много.** Бесплатный ящик подходит для начала, но Яндекс и Mail.ru ограничивают число писем в день и могут временно заблокировать ящик за похожую на рассылку отправку. Когда учеников станет много, подключите почту на своём домене (например, Яндекс 360 для бизнеса) или сервис транзакционных писем — у них тоже есть SMTP: впишите их `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER` и `SMTP_PASS`.

## Админка

1. Впишите свою почту в `.env.local`: `ADMIN_EMAILS=вы@почта.ru` (несколько — через запятую). Это должна быть почта вашего аккаунта на сайте.
2. Перезапустите сайт и войдите с этой почтой. В шапке появится ссылка «Админка» (страница `/admin`), а в кабинете — карточка с новыми обращениями, сообщениями в поддержку и регистрациями.

Что есть в админке:
- **Обзор**: сколько пользователей, обращений, уроков и запросов к ИИ, последние действия и что подключено (почта, ИИ, видео, поддержка), кнопка тестового письма.
- **Обращения** — вопросы из формы «Остались вопросы?» на главной. Ответьте человеку по оставленному контакту и нажмите «Отметить обработанным».
- **Поддержка** — сообщения пользователей приходят в ваши «Сообщения» (раздел «Поддержка»). Ответ увидит только тот, кто написал.
- **Пользователи**: роль, когда зарегистрировался и был на сайте, сколько уроков и запросов к ИИ.
- **Журнал**: регистрации, входы (и неудачные попытки), смены пароля, созданные уроки, подключения к урокам, обращения, принятые приглашения, сообщения в поддержку и запросы к ИИ.

## Показать сайт другу

Можно дать другу ссылку на сайт, который запущен на вашем компьютере, — без сервера и домена. Ссылка работает, пока открыто окно и включён компьютер.

1. **Ссылка.** Сначала закройте окно `start-windows.bat`, если оно открыто: это режим «для себя», он медленный, и показывать его по ссылке скрипт не станет. Дважды щёлкните `share-windows.bat` (macOS и Linux: `npm run share`). В первый раз скрипт соберёт сайт (1–3 минуты) и скачает программу **Tuna** — это российский сервис ссылок. Его серверы в России, поэтому провайдеры его не замедляют, а ссылка постоянная, вида `https://brave-otter-4821.ru.tuna.am`.
   - Для Tuna нужен бесплатный аккаунт, войти нужно один раз. В браузере откроется страница Tuna: войдите через Яндекс, Mail.ru, Google или по почте (если аккаунта нет — «Зарегистрироваться»). Проверьте, что код на странице совпадает с кодом в чёрном окне, и подтвердите вход.
   - В окне появится строка «Ссылка для друга: …». Ссылка уже скопирована — вставьте её другу в сообщение (`Ctrl+V`).
   - При первом заходе друг увидит страницу Tuna с предупреждением (так Tuna защищается от мошенников). Пусть нажмёт кнопку перехода на сайт.

   Скрипт сам проверяет ссылку: открывается ли по ней сайт и проходят ли большие страницы. Если с Tuna не получится (или вы не стали входить), он возьмёт запасные сервисы: Cloudflare, Tunnelmole, Pinggy. У Pinggy друг сначала увидит страницу на английском и нажмёт «Enter site», ссылка работает 60 минут. Пока окно открыто, скрипт следит за ссылкой. Если связь пропала, он переподключится сам. Если адрес при этом сменился, в окне появится «НОВАЯ ссылка для друга».

   Кнопки «Скопировать ссылку» на сайте сами подставляют адрес ссылки для друга, даже если у вас сайт открыт как `localhost`.
2. **Видео.** Видеосервер на вашем компьютере из интернета не виден, поэтому для урока с другом подключите бесплатный LiveKit Cloud:
   - зарегистрируйтесь на [cloud.livekit.io](https://cloud.livekit.io) и создайте проект;
   - в Settings → API Keys создайте ключ и скопируйте URL (`wss://….livekit.cloud`), API Key и API Secret;
   - замените в `.env.local` строки видео:

     ```bash
     LIVEKIT_URL=wss://ваш-проект.livekit.cloud
     LIVEKIT_API_KEY=ваш-API-Key
     LIVEKIT_API_SECRET=ваш-API-Secret
     ```
   - закройте окно и снова запустите `share-windows.bat`.

   Бесплатного тарифа хватает для первых уроков. Обычный `start-windows.bat` после этого тоже будет использовать облако — это нормально. Чтобы вернуть видеосервер на компьютере, верните значения `ws://localhost:7880`, `devkey` и `secret`.
3. **Урок с другом.** Проще всего так: создайте урок, нажмите «Скопировать ссылку» и отправьте её другу — он зайдёт как гость, без регистрации. Если друг всё же регистрируется, а письмо с кодом не пришло (или почта не настроена), код появится в вашем чёрном окне (строка «Код для …») — продиктуйте его.

Если ссылка не появляется, скрипт напишет причину. Подробности — в папке `tools`: `share.log` и файлы сервисов (`tuna.log`, `cloudflared.log` и другие). Частые причины: мешает антивирус (разрешите программам tuna, cloudflared, node и ssh работать), VPN или провайдер.

Настройки в `.env.local` (обычно не нужны):
- `SHARE_SERVICE=cloudflare` (или `tunnelmole`, `pinggy`, `tuna`) — с какого сервиса начинать. Например, если не хотите заводить аккаунт Tuna.
- `TUNA_API_KEY=…` — вход в Tuna по API-ключу вместо браузера: [my.tuna.am](https://my.tuna.am/api_keys) → API-ключи, с правом «Запуск туннелей».

### Если связь рвётся

Российские провайдеры часто замедляют зарубежные сервисы: Cloudflare, Tunnelmole, Pinggy и видео LiveKit Cloud. Маленькие ответы проходят, а большие страницы обрываются, поэтому сайт открывается через раз, а видео зависает. Поэтому первой идёт российская Tuna. Если в окне написано «большие страницы почти не проходят», причина именно в замедлении.

- Откройте только одно окно `share-windows.bat`, без `start-windows.bat`. У Tuna на бесплатном тарифе одна ссылка за раз.
- Если сайт по ссылке открывается, а видео в уроке зависает, причина в LiveKit Cloud: он зарубежный. Попробуйте VPN у обоих — и у вас, и у друга. Но VPN часто не пропускает почту: если письма с кодами перестанут уходить, коды всё равно будут в чёрном окне.
- Для постоянных занятий лучше свой сервер в России (раздел «Как выложить сайт в интернет», вариант Б). Тогда и сайт, и видео работают на вашем сервере, а компьютер можно выключать.

## Как обновить до новой версии

1. Закройте чёрное окно сайта.
2. Распакуйте новый архив поверх старого: правой кнопкой → «Извлечь всё» и в поле адреса укажите папку, **в которой лежит** старая папка `parta`. Например, если проект в `C:\Users\Имя\Desktop\parta`, укажите `C:\Users\Имя\Desktop`. На вопрос Windows выберите «Заменить файлы в папке назначения».
3. Запустите `start-windows.bat`. Скрипт сам доустановит новые библиотеки и допишет в `.env.local` новые настройки (пустыми — заполните, если нужно).

Ваши настройки (`.env.local`) и база данных (папка `data`) в архиве не лежат, поэтому не пропадут. Для надёжности перед обновлением можно скопировать их в другое место.

## Как выложить сайт в интернет

### Вариант А: облако (проще всего)

1. **База данных.** Создайте бесплатный проект на [neon.tech](https://neon.tech) и скопируйте строку подключения (`postgresql://…`).
2. **Видео.** Создайте проект на [cloud.livekit.io](https://cloud.livekit.io). В разделе Settings → API Keys возьмите URL (`wss://….livekit.cloud`), API Key и API Secret.
3. **Код.** Загрузите проект на GitHub (раздел «Загрузка на GitHub» ниже).
4. **Сайт.** Зайдите на [vercel.com](https://vercel.com), нажмите Add New → Project и выберите репозиторий с GitHub. В Environment Variables добавьте:
   - `DATABASE_URL` — строка из Neon;
   - `LIVEKIT_URL`, `LIVEKIT_API_KEY`, `LIVEKIT_API_SECRET` — из LiveKit Cloud;
   - `AI_BASE_URL`, `AI_API_KEY`, `AI_MODEL_SMART`, `AI_MODEL_FAST` — для ИИ;
   - `SMTP_USER`, `SMTP_PASS` (и при необходимости `SMTP_HOST`, `SMTP_PORT`, `MAIL_FROM`) — для писем с кодами и уведомлений;
   - `ADMIN_EMAILS` — ваша почта для админки.
5. Нажмите Deploy. Через пару минут сайт откроется по адресу `….vercel.app`.

> Если ученики в основном из России, облачные сервисы могут работать медленнее. Тогда лучше вариант Б на российском сервере.

### Вариант Б: свой сервер с Docker

Подойдёт VPS с Ubuntu 22.04 или 24.04, от 2 ядер и 4 ГБ памяти (например, Timeweb Cloud, Selectel, Beget, Yandex Cloud). Ориентир по цене — около 1000 ₽ в месяц, точнее смотрите в тарифах хостинга.

1. **Домены.** Создайте две A-записи на IP сервера: для сайта (например, `parta.ru`) и для видео (например, `live.parta.ru`). Подробнее — в разделе «Свой домен».
2. **Docker.** Подключитесь к серверу и установите Docker:
   ```bash
   curl -fsSL https://get.docker.com | sh
   ```
3. **Проект и настройки.**
   ```bash
   git clone https://github.com/ВАШ-АККАУНТ/parta.git
   cd parta
   cp .env.example .env
   docker run --rm livekit/livekit-server generate-keys
   ```
   Если репозиторий приватный, вместо пароля GitHub спросит токен (github.com → Settings → Developer settings → Personal access tokens). Можно обойтись и без GitHub: скопировать архив на сервер командой `scp parta.zip root@IP-сервера:` и распаковать (`apt install unzip`, затем `unzip parta.zip`).

   Откройте `.env` (например, `nano .env`) и заполните:
   - `DOMAIN=parta.ru`, `LIVEKIT_DOMAIN=live.parta.ru`;
   - `LIVEKIT_URL=wss://live.parta.ru`;
   - `LIVEKIT_API_KEY` и `LIVEKIT_API_SECRET` — ключи из команды `generate-keys`;
   - переменные ИИ, почты (`SMTP_USER`, `SMTP_PASS`) и `ADMIN_EMAILS`.
   `DATABASE_URL` можно оставить пустым: база будет храниться в папке `data/`.
4. **Порты.** Откройте в панели хостинга (или в файрволе): 80 и 443 (TCP), 7881 (TCP), 3478 (UDP), 50000–60000 (UDP).
5. **Запуск.**
   ```bash
   docker compose up -d --build
   ```
   Сертификаты HTTPS Caddy получит сам. Сайт откроется по вашему домену.

Обновление: `git pull && docker compose up -d --build`. Резервная копия — папка `data/`.

### Свой домен

Домен (адрес вида `parta.ru`) покупают на год у регистратора: [reg.ru](https://www.reg.ru), [nic.ru](https://www.nic.ru), Timeweb, Beget и другие. `parta.com` уже занят — в поиске регистратора проверьте похожие варианты: `parta.ru`, `parta.online`, `parta-school.ru`, `partaonline.ru`. Домен в зоне .ru обычно стоит несколько сотен рублей в год. Посмотрите и цену продления: она часто выше цены первого года.

Как подключить:
- **Вариант А (Vercel):** в проекте откройте Settings → Domains, впишите домен и нажмите Add. Vercel покажет, какие DNS-записи добавить. Откройте у регистратора управление DNS домена и добавьте их. HTTPS Vercel включит сам.
- **Вариант Б (свой сервер):** у регистратора в DNS добавьте две A-записи с IP сервера: `@` (сам домен) и `live` (видео, получится `live.parta.ru`). Впишите домены в `.env` (`DOMAIN`, `LIVEKIT_DOMAIN`, `LIVEKIT_URL`) и выполните `docker compose up -d`.

Новые DNS-записи начинают работать через 15 минут — несколько часов.

## Загрузка на GitHub

Нужна для варианта А (Vercel берёт код из GitHub) и удобна для варианта Б. Проще всего через программу [GitHub Desktop](https://desktop.github.com):

1. Установите её и войдите в свой аккаунт GitHub.
2. File → Add local repository → выберите папку `parta`. Программа скажет, что это ещё не репозиторий, — нажмите «create a repository», затем Create repository.
3. Нажмите Publish repository и оставьте галочку Keep this code private. Если пустой репозиторий на GitHub уже создан, сначала укажите его адрес: Repository → Repository settings → Remote (`https://github.com/ВАШ-АККАУНТ/parta.git`), затем нажмите Publish branch.
4. Дальше после изменений: внизу слева напишите, что поменялось, → Commit to main → Push origin.

Файл `.env.local` с ключами в GitHub не попадёт — он в `.gitignore`. Перед первой загрузкой проверьте, что его нет в списке файлов.

## Безопасность

- Файлы `.env` и `.env.local` с ключами не попадают в GitHub (они в `.gitignore`). Никому не пересылайте ключи. Если ключ попал в чужие руки, создайте новый у провайдера, а старый удалите.
- Пароли хранятся только в виде хэша (scrypt), вход — через защищённую cookie. После смены пароля все старые входы на других устройствах сбрасываются.
- Почта подтверждается кодом; на угадывание кода и пароля есть ограничение попыток, на загрузку файлов в урок — ограничение объёма (и проверка, что это действительно картинка).
- Изменяющие запросы (сообщения, уроки, выход из аккаунта) сайт принимает только со своих страниц, а по ссылке туннеля выдаёт cookie с приставкой `__Host-`: так чужая страница на соседнем адресе того же туннеля (например, другой `*.ru.tuna.am`) не сможет действовать от вашего имени или подсунуть свой вход.
- После входа сайт возвращает только на свои страницы (ссылки вида `/login?next=https://чужой-сайт` не сработают).
- Войти в урок может любой, у кого есть ссылка, как в Zoom. Отправляйте ссылку только ученику.
- В «Сообщениях» репетитор видит только своих учеников, ученик — своих репетиторов; переписку с поддержкой видят только администраторы.
- Если учатся жители России, по закону о персональных данных (152-ФЗ) их данные нужно хранить на серверах в России. Ещё нужны политика конфиденциальности и согласие на обработку данных (за детей — от родителей). Это ещё один довод за вариант Б с российским хостингом; детали лучше уточнить у юриста.
